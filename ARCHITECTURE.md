# Architecture

## Current executable surface

The checkout contains repository validation tooling, dedicated tests, workflow definitions and native documentation. No source adapter, battery, acquisition service or certification package is implemented. Metadata keeps domain capabilities, claims and qualified formats empty.

## Intended data flow

A prior protocol selects source implementation, full capture population, clock and intended use, processing and complete battery. An actually qualified adapter preserves the raw bytes and complete stream maps. Analysis retains distinct raw and processed populations and every failed or unavailable test. Certification uses an installed shared evidence provider. Independent verification separates common eligibility, owner conformance, exact context and source suitability.

## Ownership

Randomness Witness owns source-specific adapters, capture consumption, processing interpretation, batteries and certificates. SC-NeuroCore retains generators and native counterparts; Loop Timing Witness owns capture and timebase; Evidence Manifest Toolkit owns shared evidence operations. SC Stream Prover independently owns arithmetic assumptions. Experiment Ledger retains generic storage and provider-spend governance. Studio renders admitted existing results.

## Interpretation

Source names and different seeds do not prove equal semantics or independent streams. Packed storage and meaningful bits differ. Processing preserves original raw outcomes. The intended certificate and separate QPU/QRNG adjunct retain a statistical-only boundary. Read [the documentation architecture](docs/ARCHITECTURE.md) for planned fields, methods and operation scope.
