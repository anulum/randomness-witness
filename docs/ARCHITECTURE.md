# Repository architecture

## Current executable tooling

The repository contains metadata, source-provenance, workflow, dependency-alignment, documentation, inventory and preflight controls, plus native-tool bootstrap. Each inspects its fixed declared scope. Received metadata cannot select another policy or grant source suitability. Foundation qualification is in progress.

## Intended source-evidence boundaries

| Component | Responsibility | Required evidence |
| --- | --- | --- |
| Source admission | Actual implementation, parameters, reset, sample, index and threshold semantics | Source-specific independent trace and counterpart qualification |
| Capture | Full prior source, clock, stream and use population | Complete raw bytes, lengths, packing, maps and failed slots |
| Processing | None, declared identity, disjoint pair processing or prior resampling | Exact per-stream output and complete retained/discarded index maps |
| Batteries | Frequency, serial, autocorrelation, pairwise correlation and selected NIST programme | Every prior item, actual samples and independently justified numerical assumptions |
| Quantum adjunct | Separate QPU/QRNG acquisition, ordering and processing provenance | Actual ordered observations and matching raw/processed identities |
| Certification | Existing candidate through installed shared provider | Current common, owner and exact-context results distinct from suitability |
| Consumers | Exact source/rate/use certificate and full limitations | Genuine installed producer and independent consumer behaviour |

The intended certificate has fifteen root fields: schema_id, claims, source_ref, environment_ref, source, clock_rate, capture_ref, raw_stream_ref, raw_bit_length, processing, qpu_source_ref, battery, intended_use, suitability and qualification_boundary.

The separate intended adjunct has ten properties: schema_id, source_kind, raw_stream_ref, raw_bit_length, ordering_rule_ref, qpu_jobs, qrng_acquisition_ref, postprocessing, qualification_boundary and test_configuration_ref. Eight are unconditional; QPU jobs and QRNG acquisition follow their exclusive source branches. These are planned declarations with no registered or qualified domain format here.

The four prospective operations are capture, analyse, certify and verify. They are not installed or advertised as available commands. A completed evaluated unsuitable result differs from unavailable prerequisites and from a caller requiring eligible or suitable acceptance. Source suitability also needs actual current evidence eligibility.

The six intended source kinds are LFSR, Sobol, Halton, software RNG, QPU and QRNG. Exact implementation, shift direction, sampling phase, reset, index wrap, comparison and packing distinguish source methods. Similar names or seeds cannot establish sequence equivalence. Validate literal bits before coercion and retain all meaningful lengths, padding, stream order and failed observations.

None and declared identity have distinct provenance. Disjoint von Neumann pairs remain within each original stream. The earlier finite certificate profile records and discards an odd tail; separately strict profiles and the quantum adjunct refuse it. The prior protocol chooses that rule before observation. Resampling uses a prior stride and local phase zero, complete index complement and genuine clock interpretation. Processed success does not erase raw failure.

Frequency targets belong to the prior use protocol. Serial analysis retains every word bin and complete window convention; its finite statistic is not bounded by one. Zero variance or missing opportunities make correlation unavailable. The full selected NIST programme needs its actual revision, implementation, sample regimes, component population and error allocation. A listed component is not an executed test.

QPU job, shot and qubit order requires actual ordered observations; histograms cannot reconstruct it. QRNG has its own sample order without invented QPU fields. A passing battery cannot prove independent sampling, a source's cryptographic properties or device-independent randomness. Fixed-length assumptions do not automatically apply to adaptive stopping.
