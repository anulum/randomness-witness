# Randomness Witness

Randomness Witness is being built to preserve the exact source, capture, processing and statistical scope of bitstreams used in stochastic computing. This checkout contains repository validation tooling and documentation. Full foundation qualification is in progress. There is no installed source-qualification package, acquisition runner, public certification command or qualified source certificate.

Randomness Witness is part of the **SC Neuromorphic Computing Systems** group (SC-NEUROMORPHIC-COMPUTING-SYSTEMS). The [group and project map](https://github.com/anulum/sc-neurocore/blob/main/docs/ecosystem.md) shows the whole programme and where this repository sits in it.

## Boundary

This project owns planned source adapters, capture consumption, raw and processed statistical batteries and source/rate/intended-use certificates. SC-NeuroCore retains generator implementations and their counterparts. Loop Timing Witness owns fabric capture and timebase. Evidence Manifest Toolkit supplies shared evidence operations; SC Stream Prover independently checks arithmetic assumptions.

A passing descriptive battery cannot establish independent observations, a computation graph's joint law, cryptographic randomness or device-independent randomness. Processing success does not erase raw failure.

## Current tooling

Seven repository controls inspect metadata, source attribution, workflows, dependency alignment, native documentation, inventory and preflight orchestration. Native-tool bootstrap verifies selected development executable and licence bytes. Metadata declares architecture-only maturity with empty implemented domain capability and claim inventories.

Use the exact environment in [Contributing](CONTRIBUTING.md). Named commands are make metadata, make source-provenance, make workflows, make dependencies, make docs, make inventory and make licence. Full CI/preflight belongs in CI or an explicitly admitted pre-push environment. See [Validation](VALIDATION.md) for the scope.

## Intended evidence

The intended certificate binds one actual source implementation, complete meaningful stream population, packing and order, processing, qualified clock and declared use. A separate QPU/QRNG adjunct preserves acquisition and ordering provenance. Unknown source, model, sample or clock conditions remain unavailable. Neither format is registered or qualified by this foundation.
